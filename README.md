# Практическая работа №4. PHP: формы и обработка данных

Небольшое PHP-приложение без MVC: таблица сотрудников из `dataset/employees.csv`,
фильтр по отделу (GET) и форма заявки сотрудника (POST) с серверной валидацией.
Технологии: PHP 8, HTML.

## Требования
- PHP 8.1+ (`php -v`)

## Запуск
```bash
git clone https://github.com/artem-puzo/trpo-04.git
cd trpo-04
php -S localhost:8000 -t public
```
Адрес: http://localhost:8000

## Структура
- `public/index.php` — точка входа, обработка GET/POST, HTML
- `src/functions.php` — функции: e, loadEmployees, parseEmployeeRow, filterEmployees, validateInput
- `dataset/` — employees.csv, form_cases.json
- `tests/run_cases.php` — проверка сценариев из form_cases.json
- `docs/` — результаты проверок

## Сценарий проверки
1. Открыть страницу: видны версия, дата и таблица из 5 сотрудников.
2. Выбрать отдел в фильтре: остаются только сотрудники этого отдела.
3. Отправить пустую форму: ошибки у полей, введённые значения сохраняются.
4. Ввести в ФИО `<script>alert(1)</script>`: выводится как текст.
5. `php tests/run_cases.php`: все кейсы OK.

## GET и POST
GET передаёт параметры в URL, подходит для фильтров и поиска, не меняет данные.
POST передаёт данные в теле запроса, подходит для отправки форм.

## htmlspecialchars
Превращает `<`, `>`, `&`, кавычки в безопасные сущности, чтобы введённый пользователем
текст не исполнялся как HTML или JavaScript — защита от XSS.

## Путь данных от формы до HTML
Форма отправляет POST, затем `$_POST[...] ?? ''` и `trim`, затем `validateInput` возвращает массив ошибок,
затем при ошибках выводится список и значения остаются в полях, при успехе показывается подтверждение,
любое значение при выводе проходит через `e()` (htmlspecialchars).
